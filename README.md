# 酒馆你害我不浅

SillyTavern（酒馆）前端扩展。一个插件管三件事：**世界书 / 预设 / API**，三格共用同一套「跟着聊天走」的逻辑——每个聊天记自己那一套，切到哪个聊天就套用哪个。

> 目前只做了架子和 **世界书** 这一格；预设、API 两格在面板里灰着，写着「还没做」，但数据结构（每个聊天的 `slots.world / preset / api`）已经留好位置，后面可以直接接上。

## 怎么装

1. 酒馆 → 扩展（拼图图标）→ **安装扩展**
2. 填仓库地址：`https://github.com/zhouyesyes/tavern-ruined-me`，选「只给我自己」或「所有人」
3. 装完刷新页面，在扩展设置里找到折叠条「**酒馆你害我不浅**」

**仓库是私有的怎么办？** 酒馆「安装扩展」是匿名拉取，私有仓库会装不上。两种办法：
- 把仓库改成公开（代码里没有任何密钥，可以公开）；或
- 手动装：把仓库下载/克隆到酒馆目录 `public/scripts/extensions/third-party/tavern-ruined-me`（用户级则是 `data/<用户>/extensions/tavern-ruined-me`），刷新页面。私有仓库用你自己的 GitHub 账号克隆即可。

## 世界书这一格

- **条目分组**：每个条目归一个桶——常开、常关、不管（默认，原样照书）、自定义组（单选下拉 / 多选勾选）。组可以写名字和说明，按书区分。
- **整本开关**：某本书在这个聊天里整本开或整本关。（一本书要么按条目分组，要么整本开关，二选一。）
- **新聊天自动弹窗**问选哪些；切回老聊天不弹。弹窗只放要选的自定义组（和整本开关），常开常关不摆出来。
- 面板里「**重选当前聊天**」随时重选。（不做斜杠命令。）
- 快捷回复栏的「**Lore 状态**」按钮：看当前聊天开了哪些。
- **写回原书**：选择会同步进原书条目的 `disable`。拨完停约 0.8 秒合并成一次保存，没变化不存，切聊天时按那个聊天再写一次；每本书第一次写回前整本备份，面板里的 ↺ 一键恢复（恢复后会暂停该书的写回，可用「写回」勾选重新打开）。这样兔子镜这类只读原书的插件也认得到。
- 打开酒馆自带的世界书页面：被接管的条目开关、变暗跟着当前聊天走，条目最上面单独一行小字「聊天配置 · 会同步到原书」，不挡任何按钮。被接管的开关不可点，要改请用面板。

### 「跟着聊天走」
每个聊天把自己的选择存在聊天元数据里（`chat_metadata.tavern_ruined_me.slots`）。新开的聊天先沿用酒馆当前的状态（条目现在开着就预选），点「确定」后才记成这个聊天自己的；没记过的聊天，自定义组和整本开关一律原样照书。

### 外观
颜色、字体全部读酒馆主题的 CSS 变量（`--SmartThemeBodyColor` 等），换美化会跟着变。手机窄屏可用。

## 开发与测试

没有构建步骤。
```sh
npm i --prefix /tmp/jsd jsdom@26 --no-package-lock
NODE_PATH=/tmp/jsd/node_modules node --test tests/*.test.mjs
```
`tests/core.test.mjs` 测纯逻辑，`tests/ui.test.mjs` 用 jsdom 模拟酒馆测面板、写回、切聊天、原生页面。真酒馆里的表现需要手动验证。

目录：`index.js` 入口；`src/core.mjs` 纯逻辑；`src/ui.mjs` 界面和酒馆衔接；`style.css`。
